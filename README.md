#Bank Customer Churn Predictor

An end-to-end Machine Learning web application that predicts bank customer churn based on account features. Built with Python and Streamlit.

##Project Structure
- `app.py`: Streamlit application interface.
- `churn_model.pkl`: Trained machine learning model.
- `model_features.pkl`: Saved feature processing specifications.
- `requirement.txt`: Python package dependencies.
